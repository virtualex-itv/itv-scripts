# legacy

Scripts for products and versions that are no longer current.  They are kept for reference and are not maintained.

* ## [powershell/powercli](https://github.com/virtualex-itv/itv-scripts/tree/master/legacy/powershell/powercli)
  ESXi image-profile (`HostImageProfile-*`) and VIB (`HostVIB-*`) scripts from the ESXi 7 and 8 era.
* ## [shell/bash/vsm](https://github.com/virtualex-itv/itv-scripts/tree/master/legacy/shell/bash/vsm)
  Install and update scripts for LinuxVSM, which is no longer available.

The ESXi-Customizer-PS script that used to sit next to these is no longer bundled; use its project instead: https://github.com/VFrontDe-Org/ESXi-Customizer-PS
